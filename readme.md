# 便捷使用网页大模型（浏览器插件）
## 概述：
### 背景
本人在用deepseek网页端指导我进行复杂任务的时候，发现多轮对话后上下文增长导致模型智商下降，而上下文中有很多冗余的信息，我需要把对话复制到记事本，手动剔除冗余部分，再在网页上新建对话，把处理好的对话发送到上去；
### 面向的问题
这个过程中，有几个麻烦的点：
1.复制的时候可能要手动关闭思考内容，不然会把思考内容复制进去，浪费上下文空间
2.直接ctrl+a会把整个页面复制，导致只能用鼠标手动选取文字复制，需要滚动遍历整个页面
3.处理大段对话翻来翻去很麻烦，不好定位到想找的位置
4.处理了的上下文发到浏览器，会被认为是一段话，不方便在浏览器中跳转到某段具体的话
### 提供的解决方案
用程序精确匹配用户提问和大模型的回答，去除大模型的思考内容；
一个按钮直接把匹配的内容提取到编辑区；
在编辑区建有对话目录，点击即可滑动到相应文本行；
按照自己喜好编辑之后按复制按钮一键复制；
### 适用浏览器和网页：
#### 浏览器：
目前只适配edge
#### 网页：
deepseek(国内版) chatglm(智谱) xiaomimimo qianwen(千问国内版) 
## 快速开始
### 方式一：直接在edge插件商城搜索“便捷使用网页大模型”或“Use web llm easily”
目前插件还在微软商店审核，可以直接下载源码
### 方式二：下载源码装到edge（不要任何依赖或者复杂操作，只需要在浏览器简单操作几步）
下载zip文件，解压到特定文件夹比如C:\User\easy-->
打开edge浏览器在地址栏输入edge://extensions/，点回车进入扩展管理页面-->
在左侧栏找到开发人员模式，点击启用-->
找到加载解压缩的扩展，点击，然后选择刚才解压zip到的的文件夹C:\User\easy（替换为你实际解压到的文件夹）-->
这时候就会出现“便捷使用网页大模型”这个插件在插件列表，点击开关启用-->
然后打开您和大模型的聊天记录，点击右上角的扩展，点击“便捷使用网页大模型”扩展，点击提取按钮，就可以方便使用啦（可以把此扩展固定，使用更方便）

## 此插件重视安全，所有数据均只存在本地，源码公开方便大家检阅
## 常见问题
1.编辑框里的对话不完整
解决：可以滑动到对话页面顶部，让之前的页面加载出来，然后重新点击按钮提取
2.deepseek报过插件导致页面崩溃，刷新浏览器界面即可（频率极低）
